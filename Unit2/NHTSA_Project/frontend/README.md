# Frontend placeholder

This is a minimal Next.js app that exists only so Vercel can deploy a valid frontend project from this directory.

## Current intent

- Keep the structure Vercel-ready.
- Avoid adding real product logic yet.
- Give the frontend team a clean handoff point.

## Important files

- `app/layout.tsx`: required root layout for the App Router
- `app/page.tsx`: placeholder homepage
- `package.json`: minimal Next.js scripts and dependencies
