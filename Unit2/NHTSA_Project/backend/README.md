# Backend placeholder

This is a minimal Vercel Python backend skeleton.

## Current intent

- Keep the directory deployable on Vercel.
- Avoid introducing FastAPI or real backend behavior yet.
- Give the backend team a clean starting point that already has a live route.

## Important files

- `api/index.py`: placeholder Vercel Python function
- `vercel.json`: rewrites `/` to the placeholder function route
- `requirements.txt`: empty on purpose because no third-party packages are required yet
